# Terminal-Universe

Project website for **Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments**.

- [Paper](https://arxiv.org/abs/2609.04148)
- [Hugging Face paper page](https://huggingface.co/papers/2609.04148)

This repository contains the standalone project website: HTML, CSS, JavaScript, and media. It has no dependency on the personal homepage or Jekyll.

## Local preview

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

Project website: https://terminal-universe-project.github.io/

## Publishing

Publish the repository root with GitHub Pages. `.nojekyll` keeps the static files unchanged. Before changing the public URL, update the canonical URL and other absolute page metadata, then preserve links from the previous address with a redirect.
